# Դիպլոմային աշխատանք — LaTeX

Այս պահոցը պարունակում է դիպլոմային աշխատանքի LaTeX աղբյուրը։

- `main.tex` — հիմնական LaTeX ֆայլը
- `assets/` — սկզբնական PDF-ից պահպանված բանաձևերի և գծապատկերների նկարները

## Հավաքում

Անհրաժեշտ է XeLaTeX և `fontspec`, `unicode-math`, `graphicx`, `amsmath`, `setspace`, `indentfirst`, `enumitem`, `float`, `hyperref`, `xcolor` փաթեթները։ Գործարկեք՝

```bash
xelatex main.tex
xelatex main.tex
```

GitHub-ը պահպանում և ցուցադրում է `.tex` աղբյուրը, բայց ինքնուրույն PDF չի հավաքում։ Առանց տեղային ծրագրի կարող եք նույն ֆայլերն օգտագործել Overleaf-ում՝ որպես նախագիծ վերբեռնելով ZIP-ը և compiler-ը ընտրելով **XeLaTeX**։

**Նշում.** Որոշ բանաձևեր և պատկերներ դեռևս պահպանված են `assets/` թղթապանակում որպես PNG, այլ ոչ խմբագրելի LaTeX արտահայտություններ։
